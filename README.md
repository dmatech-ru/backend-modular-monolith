# Backend Modular Monolith

Реализация бэкенд-сервиса на Go с использованием архитектуры **модульного монолита (Modular Monolith)**. Проект спроектирован с упором на слабую связанность компонентов (low coupling) и высокую изолированность бизнес-доменов внутри единого бинарника.

## 🚀 Особенности архитектуры
- **Модульность:** Каждый бизнес-домен изолирован в отдельный модуль со своими слоями (API, Use Case, Repository).
- **Единое приложение:** Все модули компилируются и запускаются в рамках одного процесса, что упрощает деплой и снижает задержки.
- **Инверсия зависимостей:** Взаимодействие между модулями происходит через четко описанные интерфейсы/события.
